Privacy policy

Last updated: 21 November 2026

Who uses Clio

Clio is a personal tool. It runs only on its developer's own Mac and connects only to the developer's own Google accounts. It has no other users and no server of its own.

What Google data Clio accesses

  • Gmail: reading messages and threads, and creating drafts. Clio cannot send email.
  • Google Calendar: reading calendars and events, and creating, changing or deleting events after the user confirms each change.

How the data is used

The data is used only to show the user summaries of his own mail and calendar and to carry out actions he explicitly confirms. Message and event content that is needed to answer the user's request is sent to the Anthropic Claude API for processing. Nothing is used for advertising, sold, or shared with anyone else.

Storage

OAuth tokens are stored only on the developer's computer, in files readable only by his macOS user account. Clio keeps no copies of email or calendar content beyond what is needed for the current conversation. The user can revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Clio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
